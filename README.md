# SpendWise Dashboard Shell

A responsive SpendWise Banking & Savings Dashboard built for the Week 4 Web Development assignment.

## Features
- Sidebar/navigation menu and dashboard header
- Six financial category cards with realistic static banking and savings information
- Recent transactions and savings goal panels
- CSS Grid for the overall page and major sections
- Flexbox for the header, sidebar navigation, transactions, and card content
- CSS custom properties for brand, accent, surface/background, primary text, and secondary text
- Responsive single-column layout below 768px
- Hover and keyboard focus card micro-interactions under 250ms
- Dark theme using @media (prefers-color-scheme: dark)
- No absolute positioning for page layout
- Contact email: puotmalou@gmail.com

## Files
- index.html — dashboard structure and static content
- style.css — Grid, Flexbox, responsive styles, variables, interactions, and dark theme
- README.md — project documentation

## Testing
Open index.html in a browser or use VS Code Live Server. Use Chrome DevTools → Device Toolbar to verify the layout above and below 768px.
